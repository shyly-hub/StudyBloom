# 🌸 StudyBloom

StudyBloom is a cross-platform mobile application built with **React Native** and **Expo**. It helps students track study habits, set focus timers, and analyze productivity trends over time.

---

## 🛠️ Tech Stack
* **Framework:** React Native (Expo)
* **Language:** JavaScript
* **Database & Storage:** Async Storage / Context API

---

## ✨ Core Features
* **Custom Focus Timers:** Customizable Pomodoro timer cycles for targeted study sessions.
* **Habit & Analytics Tracking:** Behavioral analysis and session logs to track weekly productivity.
* **Responsive UI:** Clean, modern mobile user interface tailored for seamless navigation.
